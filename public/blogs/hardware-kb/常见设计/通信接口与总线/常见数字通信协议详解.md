# 通信接口与总线协议详解

在硬件开发、逻辑分析仪解码以及单片机外设调试中，常见的数字通信总线主要包含以下几种：

## 1. I²C (Inter-Integrated Circuit)
* **简介**：由飞利浦(NXP)开发的双线制、半双工、同步串行总线。
* **物理连线**：SDA (数据线) 和 SCL (时钟线)。
* **硬件特性**：必须是**开漏/开集(Open-Drain/Open-Collector)**输出，总线必须外接上拉电阻（通常 4.7kΩ 或 10kΩ）。通过“线与”逻辑，支持多主机、多从机接入。
* **时序与协议**：
  * **起始条件(Start)**：SCL 为高时，SDA 由高变低。
  * **停止条件(Stop)**：SCL 为高时，SDA 由低变高。
  * **应答(ACK)**：每传输8 bit数据，第9个时钟周期，接收方拉低SDA电平表示应答。
* **速率**：标准模式 100kbps，快速模式 400kbps，高速模式可达 3.4Mbps。

## 2. SPI (Serial Peripheral Interface)
* **简介**：由摩托罗拉开发的四线制、全双工、同步串行通信接口。
* **物理连线**：
  * **SCLK**：时钟
  * **MOSI**：主出从入 (Master Output Slave Input)
  * **MISO**：主入从出
  * **CS/SS**：片选线 (Chip Select)，拉低有效。
* **硬件特性**：推挽输出驱动，速率极高（几十Mbps）。没有寻址开销，直接通过拉低对应从机的CS线进行通信。因此接多个从机需要多根CS引脚。
* **时序要求 (极性与相位)**：
  * CPOL (Clock Polarity)：决定空闲时SCLK为高还是低。
  * CPHA (Clock Phase)：决定是在第一个跳变沿还是第二个跳变沿采样数据。
  * 共组合出4种 SPI 模式（Mode 0, 1, 2, 3）。调试时若发现收发数据位全错或者移位，大多是 CPHA/CPOL 设错了。

## 3. UART (Universal Asynchronous Receiver-Transmitter)
* **简介**：通用的异步收发传输器。常配合芯片如 MAX232, MAX3485 转换为 RS-232 或 RS-485 电平。
* **物理连线**：TX (发送), RX (接收), GND (共地)。属于全双工。
* **硬件特性**：异步通信（无需时钟线）。双方必须预先约定好**波特率(Baud Rate)**。
* **帧结构**：起始位(1 bit低电平) + 数据位(通常 8 bit) + 校验位(奇/偶/无) + 停止位(1或2 bit高电平)。

## 4. CAN 總線 (Controller Area Network)
* **简介**：博世公司开发的车载和工业网络总线标准。
* **物理连线**：CAN_H, CAN_L 构成的差分信号线。两端必须接 **120Ω 的终端电阻** 以防止信号反射。
* **硬件特性**：
  * **隐性状态 (Recessive)**：逻辑 1，两线电压均为约 2.5V，无压差。
  * **显性状态 (Dominant)**：逻辑 0，CAN_H 约 3.5V，CAN_L 约 1.5V，压差约 2V。
  * 具备极强的抗干扰性和自动仲裁机制 (ID越小的报文优先级越高，且能覆盖隐性状态)。

## 5. 调试建议 (逻辑分析仪抓包)
* 抓取 I2C 时，确保逻辑分析仪的采样率至少是总线速率的 5-10 倍。
* 如果 I2C 抓不到 ACK，通常是从机地址写错了（注意 7-bit 地址是否有算上读写位，即是否发生了左移）。
