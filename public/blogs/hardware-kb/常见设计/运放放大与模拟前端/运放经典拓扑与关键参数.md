# 运算放大器 (Operational Amplifier) 基础与关键参数

运算放大器被誉为模拟电路中的“瑞士军刀”。在测控设备、模拟前端(AFE)以及信号调理中无可替代。

## 1. 经典放大电路拓扑
*(注：以下计算基于理想运放原理：“虚短”$V_+ = V_-$ 与 “虚断”$I_+ = I_- = 0$)*

* **反相放大器 (Inverting Amplifier)**：
  * 信号从反相端(-)进入。同相端(+)接地。
  * 增益公式：$A_{v} = - \frac{R_f}{R_{in}}$
  * 缺点是输入阻抗仅等于 $R_{in}$，对前级信号源有负载效应。
* **同相放大器 (Non-Inverting Amplifier)**：
  * 信号从同相端(+)进入。
  * 增益公式：$A_{v} = 1 + \frac{R_f}{R_g}$
  * 优点是输入阻抗极高（近乎无穷），不吸取前级电流。
* **电压跟随器 (Voltage Follower / Buffer)**：
  * 同相放大器的极限特例 ($R_f=0, R_g=\infty$)，增益 $A_{v} \approx 1$。
  * 用于前后级电路的**阻抗匹配与隔离**。
* **仪用放大器 (Instrumentation Amplifier, INA)**：
  * 由3个运放组成，极高输入阻抗和极高共模抑制比(CMRR)。广泛用于医疗(ECG脑电)、电桥(称重传感器)等微弱差分信号的精确放大。

## 2. 核心真实参数选型避坑指南
理想运放是不存在的。在真实硬件设计中，这几个参数决定成败：

* **带宽增益积 (GBW, Gain-Bandwidth Product)**：
  * 运放能处理的最高频率由它决定。由于是在开环图上的常数，所以你要的闭环增益倍数与你想要的带宽之乘积必须小于等于此参数。例如：GBW=10MHz 的运放，如果放大100倍，则它顶多只能通过 100kHz 的信号。
* **压摆率 (Slew Rate, SR)**：
  * 运放输出端电压允许变化的最大阶跃速率 (如 10V/μs)。对于高频大信号或者方波脉冲至关重要。如果 SR 不够，方波出来就会变成三角波斜坡。
* **输入失调电压 (Vos, Input Offset Voltage)**：
  * 即便输入为0，输出也会有电压。特别是当你将直流信号放大 $1000$ 倍时，如果只有 $1mV$ 的失调电压，输出端就会有 $1V$ 的巨量错误直流偏置。如果是小信号或者微欧级电流采样，必须选择零漂移或斩波稳零的高精运放。
* **共模约束 (Input Common-Mode Voltage Range)**：
  * 运放的输入电压不允许超过规定的上下限。部分运放标注了**轨到轨输入 (Rail-to-Rail Input)**，说明它允许输入从 $0V$ 直奔供电 $V_{CC}$。

## 3. 典型电源陷阱
* **单电源供电 vs 双电源供电**：
  * 许多初学者使用运放设计反相放大器或者想处理正负交流模拟信号，却只给了 $5V$ 和 $GND$ 供电。这会导致负半周的信号全部被削平(Clipping)。处理正负压信号如果没有抬升偏置，建议一定要用正负电源（例如 $\pm15V$）来给晶体管建立工作点。
