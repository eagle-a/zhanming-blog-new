# 电子负载 (Electronic Load)

## 1. 仪器简介
电子负载主要用来模拟真实的负载以测试电源、电池的特性。能够精确地吸收直流电能或交流电能，并将其耗散（通常以热能形式或回馈电网形式）。

## 2. 常见工作模式
* **恒流模式 (CC, Constant Current)**：是最常用的模式，不论输入电压如何变化，负载都吸收设定恒定的电流。常用于测试电源带载能力。
* **恒压模式 (CV, Constant Voltage)**：无论输入电流如何变化，负载两端电压保持恒定。常用于测试充电器。
* **恒阻模式 (CR, Constant Resistance)**：模拟一个恒定电阻，电流随电压变化。
* **恒功率模式 (CP, Constant Power)**：负载功率恒定，常用于电池放电测试。

## 3. 核心应用场景
* DC-DC / AC-DC 转换器测试（效率、瞬态响应、短路测试）
* 电池放电容量及寿命测试
* 太阳能电池板 / 燃料电池 特性测试

## 4. 爬虫/资料搜集建议
* **推荐搜寻关键字**：艾德克斯(ITECH)、菊水(Kikusui)、致茂(Chroma) 电子负载应用笔记、瞬态负载响应测试方法、动态负载变化测试规范。
