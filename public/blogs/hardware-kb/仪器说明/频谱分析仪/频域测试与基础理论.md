# 频谱分析仪 (Spectrum Analyzer)

## 1. 仪器简介
频谱分析仪是研究电信号频谱结构的电子测量仪器，它能在频域内展示信号的幅度和频率关系，而不像示波器主要展示时域。

## 2. 关键参数
* **频带范围**：覆盖的频率范围，如从 9kHz 到 3GHz/6GHz 取决于仪器。
* **分辨率带宽 (RBW, Resolution Bandwidth)**：能够分辨两个靠得很近信号的能力，RBW越小频率分辨率越高，但扫描时间越长。
* **视频带宽 (VBW)**：平滑显示噪声的带宽。
* **底噪 (DANL, Displayed Average Noise Level)**：决定了频谱仪能测量的最小信号电平幅度。通常与RBW设置呈 $10 \log_{10}(\frac{RBW_1}{RBW_2})$ 的关系，且受前置放大器(Preamplifier)的影响。
* **相位噪声 (Phase Noise)**：频谱仪本振信号的频谱纯度指标，表征了在偏离载波一定频率处（如10kHz处）的噪声能量，常以 dBc/Hz 为单位。

## 3. 扫频式(SA)与矢量式(VSA)的区别
* **扫频分析仪 (Swept-tuned SA)**：通过本振混频进行窄带滤波器扫描，适合看连续波信号及宽带稳态信号。
* **矢量信号分析仪 (VSA)**：结合了宽带数字化仪系统和强大的数字信号处理 (FFT)，不仅能看幅度，还能看相位，非常适合捕获瞬态信号和复杂调制解调分析（如 QAM, PSK 等）。

## 4. 检波器 (Detector) 类型及其应用
在频谱仪向显示器离散化像素展示波形时，常常要通过检波器处理“一簇”数据：
* **峰值 (Peak)**：取一个区间内的最大值。用来测量最糟糕条件下的电平或者宽带噪声信号。
* **取样 (Sample)**：随机抽取中心点或特定间隔点。适用于测量噪声电平。
* **平均/均方根 (RMS/Average)**：对区间内数据的功率进行求平均计算。用于测量信号真实功率或者宽带数字调制信号。
* **准峰值 (Quasi-Peak, QP)**：具有冲放电时间常数的加权峰值检波，常用于 EMC 测试中（对低重频的脉冲信号进行“惩罚”打折）。

## 5. 典型应用
* 射频及微波电路测试，无线电通信（Wi-Fi, 蓝牙, 5G）。
* 电磁兼容测试 (EMC/EMI) 中的辐射和传导发射测量。
* 谐波、杂散及噪声底测试。
