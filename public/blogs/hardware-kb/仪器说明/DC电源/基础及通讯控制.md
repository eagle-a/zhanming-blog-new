# 直流电源 (DC Power Supply)

## 1. 仪器简介
实验室通常使用的是可编程直流电源系统，用于给电路板、模块提供稳定纯净的直流电压和电流。

## 2. 关键参数
* **输出电压/电流/功率范围**：最大的工作输出限制。
* **纹波及噪声**：电源输出直流中夹杂的交流交流成分，好电源纹波非常低（通常＜几mV）。
* **恒压(CV) / 恒流(CC) 自动切换**：当负载变化超出预设参数时电源的保护动作。
* **可编程性与通讯接口**：是否支持 SCPI 指令串控制，带无 USB/LAN/GPIB 接口实现自动化测试。

## 3. 典型应用
* 为待测件 (DUT) 供电。
* 模拟电源波动、浪涌、跌落等特殊电源供电环境（序列发生）。
* 产品的老化测试供电。

## 4. 爬虫/资料搜集建议
* **推荐搜寻关键字**：线性电源与开关电源对比, SCPI指令控制电源, 直流电源纹波测试方法, OVP/OCP/OPP保护机制。
