## 一、主要学习内容

### 1. 传输线与端接

我理解了源阻抗 `Rs`、传输线阻抗 `Z0` 和负载阻抗 `RL` 共同决定波形反射：

```text
ΓL = (RL - Z0) / (RL + Z0)
```

当负载为高阻、接收端在线路末端时，通常使源端总输出阻抗接近 `Z0`，采用源端串联端接。这样可以利用高阻负载的正反射恢复电压，同时吸收返回源端的反射，功耗也低于负载并联端接。但端接方式还要结合上升时间、传播延迟、负载电容和接收器数量判断，不能只按“高阻”一个条件决定。

图 1：AN-807 对不同 `Rs`、`Z0`、`RL` 组合的比较。可以看到，源端和负载都不匹配时反射明显；源端匹配而负载高阻时，返回波被源端吸收，适合单个末端接收器。

### 2. ADC 精度与噪声

我认识到 ADC 的位数只是名义分辨率，系统有效精度还受量化噪声、前端运放噪声、采样电容回灌、参考和电源噪声、时钟抖动以及抗混叠滤波器影响。选择 ADC 时应先确定输入幅度、有效带宽、采样率和目标 SNR/SINAD，再进行噪声预算。时钟抖动造成的理论上限为：

```text
SNRjitter = -20 log10(2π · fIN · tj,rms)
```

运放噪声需要区分低频的闪烁噪声和中高频的白噪声，并按实际噪声增益和带宽积分。FOG 仿真中的 `TIA_Noise_Budget` 和 `PD_TIA_Stability_Sweep` 让我进一步理解了散粒噪声、反馈电容、结电容和稳定性之间的关系。

差分 ADC 输入端不是理想高阻，跨接电阻和串联隔离电阻会同时影响差分负载、共模、驱动电流、噪声和建立时间。因此跨接电阻不能凭经验固定，应以芯片推荐网络为起点，通过 AC、瞬态和噪声仿真确定。

### 3. 混合信号 PCB 接地

目前更准确的理解是：重点不是“必须分割”或“绝对不分割”，而是保证连续参考平面和最短回流路径，使数字回流不要穿过模拟输入、参考和时钟区域。对很多 ADC/DAC 混合信号板，合理分区加完整地平面通常比随意切割更可靠；是否分割仍需结合层叠、器件手册和实测判断。

### 4. DAC 后级驱动

DAC 后级需要同时考虑输出类型、I/V 转换、重构滤波、运放带宽、压摆率、输出电流和负载条件。高阻负载与 50 Ω 负载的幅度和电流要求不同，不能共用一个结论。

![AD9767 高速 DAC 后级驱动仿真](/images/half-week-report-2026-09-09/ad9767-highspeed-dac.png)

## 二、阶段性认识

这几天把以下链路联系起来了：

```text
传输线端接 → ADC/DAC 接口 → 运放噪声与建立 → 电源接地 → PCB 回流 → 系统精度
```

器件选型和电阻取值不能只看单个参数，必须同时考虑频带、负载、噪声、稳定性、时序和实际测量条件。
